# Contribuyendo con Postguy

¡Gracias por tu interés en contribuir! Antes de abrir un Pull Request, lee lo siguiente.

## Cómo contribuir

1. Abre un Issue describiendo el error o la funcionalidad propuesta, para alinear antes de programar (evita retrabajo).
2. Haz un fork del repositorio y crea una rama a partir de `main`.
3. Sigue el estilo de código ya usado en el proyecto.
4. Prueba tus cambios localmente antes de abrir el PR.
5. Describe claramente, en la descripción del PR, qué se cambió y por qué.

## Licenciamiento de las contribuciones y Contributor Agreement

Este proyecto usa un modelo de **doble licencia**: está disponible
públicamente bajo [AGPLv3](LICENSE), y también se ofrece bajo una
[licencia comercial separada](COMMERCIAL-LICENSE.es.md) para quienes no
pueden cumplir con los términos de la AGPLv3.

Para que este modelo funcione legalmente, es necesario que el mantenedor
del proyecto (Roger Philippe Pereira) tenga los derechos necesarios para
relicenciar comercialmente el código completo, incluyendo contribuciones
de terceros.

**Al enviar una contribución (Pull Request, parche o cualquier otro
material) a este proyecto, aceptas que:**

1. Tu contribución se licencia bajo la AGPLv3, como el resto del proyecto; y

Si no estás de acuerdo con estos términos, lamentablemente no podemos
aceptar tu contribución a este proyecto.
