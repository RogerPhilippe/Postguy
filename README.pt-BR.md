# Postguy

Cliente HTTP para o navegador — envie requisições, inspecione respostas, sem instalar nada.

Backend em Kotlin/Ktor executa as chamadas HTTP (evitando bloqueio de CORS) e serve a interface React na mesma porta.

## Rodando localmente

Requisitos: JDK 21+, Node.js 18+

```bash
./gradlew run
```

Acesse **http://localhost:8080**

## Stack

Kotlin · Ktor · React · TypeScript · Vite · Tailwind · Zustand
